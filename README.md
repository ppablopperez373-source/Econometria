# Econometría · ejercicios

Presentación web estática de los ejercicios de correlación de Pearson, regresión lineal MCO y distribución de Poisson.

## Publicación

El flujo de GitHub Actions de `.github/workflows/pages.yml` publica automáticamente el contenido del repositorio en GitHub Pages al actualizar `main`. En GitHub, configura **Settings → Pages → Build and deployment → Source: GitHub Actions**.

La página usa MathJax desde jsDelivr para representar LaTeX y necesita conexión a internet para cargar esa biblioteca.
